# jev-skill-suggestion

Плагин-модуль версии 0.1.0 (хуки и команда, не процедурный навык). Для ручного выбора навыка из каталога есть навык `jev-skill-select`.

## Что делает

- На `prompt.attachment` удерживает список навыков, так что в контексте он не занимает место.
- На `prompt.submit` делает два запроса к Jev: ранжирует все навыки с проверкой «нужен ли навык вообще», затем перечитывает три лучших вместе с их `SKILL.md` и может отклонить все. Победивший `SKILL.md` прикладывается к запросу блоком `<skill_relevance>`.
- Без ключей работает встроенный классификатор движка.

## Команда `/jev-skill-suggestion:setup`

Файл `commands/setup.md`. Переводит навыки в режим «только вручную» через `skillOverrides` в `~/.claude/settings.json`, после чего `/context` считает их как 0. Перед правкой сохраняет прежние значения в `~/.claude/jev-skill-suggestion.skill-overrides.backup.json`. Аргумент `restore` откатывает. Правка `settings.json` меняет общее состояние: показывать диф и ждать подтверждения.

## Файлы

- `README.md` — быстрый старт из пяти шагов (запуск требует `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`, Claude Code 2.1.278+).
- `hooks/hooks.json`, `hooks/jev-skill-suggestion.ts`, `hooks/policy.ts` — хук и политика.
- `tests/policy.test.ts` — тесты политики.
- `.claude-plugin/plugin.json` — манифест и настройки (ключи секретные, не печатать).

## Оговорки

- Статус подключения не проверен: в `~/.claude/plugins/installed_plugins.json` плагина нет, но README описывает автозагрузку из `.claude/skills/` как `jev-skill-suggestion@skills-dir`, а для `~/.claude/skills/` это не выяснялось.
- Не запускать `setup`, не проверив, что модуль загружен: без него команда ничего полезного не делает.
