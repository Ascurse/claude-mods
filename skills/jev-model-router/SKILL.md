# jev-model-router

Плагин-модуль версии 0.4.2 (хуки Claude Code, не процедурный навык). Для выбора линии модели при делегировании используй навык `jev-model-routing`; этот каталог — реализация на хуках.

## Что делает

- На `agent.spawn` выбирает модель подагента (переключатель `routeSubagentModel`, по умолчанию включён).
- На `turn.step` выбирает усилие рассуждения основного цикла (`routeMainEffort`, по умолчанию включён) и, если разрешено, модель (`routeMainModel`, по умолчанию выключен: смена модели посреди сессии сбрасывает кэш промпта).
- Решает в обе стороны: механическую работу отправляет вниз, тяжёлую — вверх.
- Бэкенды: собственный API TypeSafe (`jev-latest`, приоритетный: даёт калиброванную уверенность) или Vercel AI Gateway. Без ключей работает встроенный классификатор движка.

## Файлы

- `README.md` — полное описание, таблица переключателей, правила порога уверенности.
- `hooks/hooks.json` — подключает модуль `./jev-model-router.ts`.
- `hooks/jev-model-router.ts` — сам хук; `hooks/policy.ts` — решение по ответу Jev.
- `tests/policy.test.ts` — тесты политики.
- `.claude-plugin/plugin.json` — манифест и настройки пользователя (ключи помечены как секретные).

## Правила

- Ключи TypeSafe и Gateway не печатать и не логировать.
- Перед изменением политики читать `README.md` («How it decides») и гонять `tests/policy.test.ts`.

## Оговорка

Статус подключения не проверен: в `~/.claude/plugins/installed_plugins.json` плагина нет, но README описывает автозагрузку из `.claude/skills/` как `jev-model-router@skills-dir`, а для `~/.claude/skills/` это не выяснялось.
