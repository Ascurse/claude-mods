# prompt-cache-control

Плагин-модуль версии 0.1.0 (хуки и интерфейс, не процедурный навык). Показывает над строкой ввода, сколько токенов запрос прочитал из кэша, записал и отправил мимо кэша, плюс обратный отсчёт до истечения кэша и подсказку: продолжать, `/compact` или `/clear`.

## Как читать полосу

- `read` — взято из кэша, `wrote` — записано в кэш, `new` — не кэшировалось.
- Время жизни кэша: 5 минут или 1 час. Модуль берёт его по правилам самого Claude Code (опция `ttl`, `FORCE_PROMPT_CACHING_5M`, `CLAUDE_CODE_PROMPT_CACHE_TTL`, настройка `promptCacheTtl`, `ENABLE_PROMPT_CACHING_1H`, затем тип аккаунта) и поправляет по фактическим паузам между запросами.
- Дорогой момент — истёкший кэш при большом контексте: следующее сообщение перезапишет весь контекст. Тогда модуль советует `/compact` (или `/clear`, если задача закончена).
- Смена модели, усилия рассуждения, набора инструментов, системного промпта или `CLAUDE.md` тоже сбрасывает кэш.

## Команда

`/cache` открывает панель с таблицей по ходам, полосой оставшегося времени и разбивкой последнего запроса.

## Файлы

- `README.md` — правила TTL и цены записи/чтения кэша.
- `hooks/hooks.json` — подключает `./prompt-cache-control.tsx`.
- `hooks/prompt-cache-control.tsx` — отрисовка полосы и панели; `hooks/cache.ts` — подсчёт и вывод TTL.
- `tests/cache.test.tsx` — тесты.
- `.claude-plugin/plugin.json` — манифест и настройки (`ttl`, `warnSeconds`).
