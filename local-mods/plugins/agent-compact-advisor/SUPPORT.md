# Getting help

- **Questions, bugs and ideas**: open an
  [issue](https://github.com/apolenkov/agent-compact-advisor/issues/new/choose). Include your
  Claude Code version (`claude --version`), the mod's version from
  `/plugin`, and what you saw.
- **Security problems**: do not open a public issue; follow
  [SECURITY.md](SECURITY.md) to report privately.
- **Working on the code**: see [CONTRIBUTING.md](CONTRIBUTING.md).

Sibling mods are listed in the
[agent-mods](https://github.com/apolenkov/agent-mods) marketplace; each has
its own issue tracker.
