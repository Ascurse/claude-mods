# engine-types/claude-code.d.ts

`claude-code.d.ts` is the Claude Code function-hooks API declaration file, written by
Claude Code itself (its first line names the version). It is © Anthropic PBC and is
**not** covered by this repository's MIT license; it is kept here only so CI can
type-check this mod. Anthropic publishes the same file in
[anthropics/claude-code/mods/types](https://github.com/anthropics/claude-code/tree/main/mods/types).

Refresh it after a Claude Code update with `npm run update-types`.
